# New World Design Code Lookup

Source-only handoff for world design reference. This archive is intentionally lightweight and is not expected to include packaged builds, caches, screenshots, generated bytecode, logs, launch shortcuts, or historical notes.

## Flagship default

The registry now selects one long-term default world:

- `minecraft-definitive-overworld-3d` - **Minecraft Definitive Overworld**

Design intent:

- Minecraft-readable from the first frame: block DDA rendering, grass/dirt/stone strata, rivers, water, sand, snow, trees, huts, paths, crops, torches, ores, lava caves, square sun/moon, block clouds, and voxel shadows.
- Maintainable rather than ornamental: four simulation channels are documented in shader comments and kept stable enough for long-running stress-test sessions.
- Launcher-friendly: the default/primary world is first in the registry, while earlier experiments are still selectable through the legacy helpers.

## Registry behavior

- `DEFAULT_WORLD_ID` is set to `minecraft-definitive-overworld-3d`.
- `iter_primary_worlds()` returns only the default flagship world.
- `iter_legacy_worlds()` returns previous experiments for a legacy tab.
- `iter_worlds()` remains backward-compatible and returns the default first, then legacy worlds sorted by id.
- `get_world(None)` resolves to the default world.
- `python main.py --list-worlds` works without importing the OpenGL renderer dependencies.

## Included

- `engine.py` and `main.py` for the world contract and renderer entry points
- `worlds/*.py` for all registered world implementations
- `shaders/*.frag` and `shaders/*.vert` for shared shader sources
- `requirements.txt` for dependency lookup
